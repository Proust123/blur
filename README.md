Blur on Password Input:
-A creative JavaScript project that removes background blur as the user types a password.

Features:
-Blurred background image that gradually clears with each keystroke in the password field.
-Interactive visual feedback that enhances user engagement.
-Built using plain HTML, CSS, and JavaScript.

How It Works:
-As the user types in the password input field, the background blur decreases dynamically.
-The effect is tied to the length of the input, providing a smooth visual transition.

Technologies Used:
-HTML5
-CSS3 (filter: blur())
-JavaScript (keyup event, DOM manipulation)
